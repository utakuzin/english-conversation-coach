English Conversation Coach (PWA) / インストール手順

1. ZIPファイルを展開して、中のファイルを確認します。
2. GitHub (https://github.com) にログインし、public リポジトリ english-conversation-coach を作ります。
3. README.txt を含めたファイル一式をリポジトリ直下にアップロードします。ZIPのままではなく展開したファイルをアップロードしてください。
4. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save。
5. 数分後、https://ユーザー名.github.io/english-conversation-coach/ にアクセスします。
6. iPhone/iPad のSafariで開き、共有メニュー > ホーム画面に追加。
7. ChatGPTで「大人A」「子ども」「大人B」それぞれのプロジェクトを作成し、各プロジェクト作成時にプロジェクト専用メモリを選択。プロジェクトごとの基本指示を登録してください。
8. PWAでメンバーを選び、レッスン設定後に「設定文をコピー」。ChatGPTで対応するプロジェクトを開いて貼り付け、送信した後に音声モードを開始します。

注意：外部アプリからChatGPTのプロジェクト・音声会話を自動操作することは保証されません。
メンバー設定はブラウザ内に保存されます。バックアップ機能で端末間の設定を移行できます。
子ども用は保護者がChatGPTとのやり取りと操作を行ってください。
APIは使用しません。公開リポジトリには個人情報や認証情報を書き込まないでください。
